Palette explorations — Yaldabaoth

Two exercises: Folio (your main theme, light) and Nightfox (dark). Each shows its true baseline plus variations. Goal across both: less warm, fewer browns, more consistent, more room for yellow.

Every specimen paints the same UX elements — workspace tab strip, two tiles (one focused), a floating command / p-menu, a dialog, a UX detail panel — for like-for-like comparison. Colors map to the roles already named in theme.rs :: OverlayTheme (bg · border · label · fg · key · accent · selected_bg · modified · input), so a chosen palette drops straight into code.
