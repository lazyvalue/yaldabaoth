A beautiful TUI markdown viewer and editor built in Rust. Designed for speed, elegance, and complexity simplicity.
Installation
rust
cargo install sketch
Note: Requires Rust 1.75 or later
• Fast rendering with ratatui
• Syntax highlighting via syntect
• Inline image support (Kitty protocol)
See the documentation for more details.

Keybindings (MVP)

↕

Scrolling

j/k — line up/down  ·  d/u — half-page  ·  gg/G — top/bottom  ·  Ctrl+f/Ctrl+b — full page

§

Structure Navigation

{/} — prev/next heading  ·  [[/]] — prev/next heading (same level)

🔍

Search

/ — search forward  ·  ? — search backward  ·  n/N — next/prev match

⌘

Actions

q — quit  ·  o — open link under cursor in browser  ·  y — yank current line
